更新日志

预览版 0.1.11 将网页搜索迁移到扩展管理的本地 SearXNG 运行时，使代理终端可见，移除任意工具循环中止，并新增模型驱动的完成度与进度审查。

0.1.11 托管搜索与持续代理执行

  • 用扩展管理的本地 SearXNG 运行时替代 Chromium 驱动的搜索。它按需启动、公开可用引擎目录、支持自定义引擎选择，并且不需要系统 Python、Docker、Podman 或浏览器。
  • 代理命令现在会在专用的 VS Code 集成终端中可见运行，保留有界结构化结果，并在完成后关闭。系统会拒绝分离式启动器并禁用 .NET 构建服务器复用，以避免产生孤儿进程。
  • 移除可配置的轮次检查点和每块调用预算。工具循环会持续到真实终止条件；长时间任务在完成 20 轮后进行独立进度审查，此后每五轮再次审查。
  • 重复调用抑制会在工作区发生修改后重置，既允许合理的重新构建，也继续阻止无效重复。
  • 流式片段之间出现的助手文本内异常 DeepSeek DSML 会被抑制，并通过原生工具调用重试一次。独立完成度审查会识别过早的纯文本停止，但不会把第二次不完整结果误报为成功。
  • 进度审查会接收紧凑的累计活动历史，并可在请求的交付物已经构建成功后停止代理自行发起的验证循环；不确定或不可用的审查不会阻塞工作。
  • 用量信息移至会话级弹出面板，提供按模型汇总；当 DeepSeek 省略部分请求的用量时，会显示可计算的最低费用。
  • 已移除 issue #61 所跟踪的旧版历史和 checkpoint 兼容逻辑。激活时会直接删除不兼容的会话和 checkpoint，不再迁移或隔离。

0.1.10 视觉、权限、输入框与取消

  • 用 DeepSeek V4 Vision (Flash) 替代非视觉 Flash。Vision 直接读取 Files API 引用；只有提示包含图像时，V4 Pro 才获得 analyze_images。
  • 当实验性 Vision 不可用时，由提供商执行一次稳定 V4 Flash 重试。图像聊天会明确说明视觉输入已省略；V4 Pro 的委托图像分析则显式失败，不会接受虚假的图像描述。
  • 文件和图像统一使用 + 选择器，支持 Ctrl+V/Cmd+V 粘贴、按签名检测 JPEG/PNG/GIF/WebP、30 天 Files API 到期、本地预览和兼容撤销的清理。
  • 权限简化为 default、auto-approve 和 full-access；移除逐工具矩阵与本地危险分析器，将 Web search 放到 Permission mode 下并提供统一开关。
  • 聊天输入区重构为紧凑单一 composer，并使用一个上下文生成按钮：草稿为空时为 Stop，有内容时按 Enter 为 Guide，按住 Ctrl 或使用 Ctrl+Enter 时为 Queue。
  • Stop 会将提示、部分 timeline 和已完成工具结果保留为 cancelled。Steering 现在会验证源生成任务，按最新指导明确继续原始任务，并隐藏内部 interrupted 传输边界。

0.1.9 并发对话隔离、取消与校准上下文

  • 并发生成现使用按对话和生成任务关联的协议事件、导航 ID、后台活动状态与快照恢复，不会将更新泄漏到其他对话。
  • Stop 会删除完整的已取消轮次，并将提示词恢复为草稿。取消会贯穿上下文发现、流式输出、浏览器、确认、工具、终端子进程和持久化，且只产生一个终止结果。
  • 自动压缩使用提供商校准的生成预算、有界 UTF-8 文本和合并的文件范围；仅记录有效缩减，并在接近上下文硬限时安全转换已闭合的工具周期。
  • 推理密集型回复获得预防性输出溢出恢复，同时保留可见的未完成状态，并兼容旧版历史和检查点。
  • Marketplace 现通过正常渠道接收构建，package.json 仍保留 preview: true；GitHub Release 继续标记为预发布。从其他 VS Code 工作区或窗口恢复的对话会自动开始一个绑定当前工作区的新对话。

0.1.8 拟人化无头搜索与隔离语义读取

  • 搜索会打开所选 Bing、Google 或 Baidu 首页，聚焦搜索框，以短暂逐键延迟输入并按 Enter 提交。默认使用 Bing；CAPTCHA、阻止和超时均为终止失败，不会升级到可见浏览器或自动重试。
  • 搜索最多返回十个规范化的自然 HTTPS URL 字符串。read_web 仅接受与 search_id 精确登记的 URL；直接 URL 仍限于用户明确提供的地址。
  • 页面读取仅保留 document.body 中的标题与段落，将相邻内容组合为稳定编号分段，在段落边界拆分过长分段，并通过不透明游标分页且不重新编号。
  • 每次读取都使用新的 128 位加密 nonce 包围 JSON 安全的不可信内容，在网页数据前后提醒忽略提示注入，并在 nonce 冲突时重新生成。
  • 设置新增独立的 API 与网页搜索标签页；移除旧版原生网页设置、可见浏览器、手动 CAPTCHA 流程和可配置用量预警预算，同时保留隔离代理与浏览限制。

0.1.7 集成浏览器搜索重构与上下文压缩

  • 将集成浏览器搜索重构为单个可复用的 VS Code 页面：搜索输入到当前引擎，已注册结果点击打开，导航通过浏览器历史返回；缺少新版浏览器工具时仍提供兼容模式。
  • 新增 DuckDuckGo、Bing、Google 和 Yahoo 的本地化回退、语义化自然结果解析、Bing 重定向解码、公网 HTTPS 校验、有界缓存、紧凑响应、语义化页面提取和经过净化的浏览器诊断。
  • 用不透明的搜索/文档 ID 与仅有的两个受限工具 search_web 和多模式 read_web，取代模型可见的页面 ID、DOM 引用、任意导航和通用链接跟随。
  • 将已完成的会话上下文压缩为用户/最终回答对，仅为进行中或未完成的恢复保留完整提供商记录，并在历史再次保存时惰性压缩重复的旧版网页输出。

0.1.6 隐私、可靠性与用量可观测性

  • 新增无痕模式：提示、引用、检查点和用量仅保留在内存中，直到用户明确保存或丢弃会话。
  • 新增按请求阶段、生成和会话聚合的提供商用量，包括嵌套推理 Token 以及独立的缓存命中/未命中计数；缺失值显示为不可用，而不是零。
  • 新增当前 DeepSeek V4 Flash/Pro 官方价格估算及持久化目录版本、本地用量明细、脱敏诊断，以及辅助调用、缓存未命中输入、输出和生成成本预警预算。
  • 强化工具调用完整性、未保存缓冲区、并发存储、部分流、进程关闭、Webview 协议协商、提供商验证、诊断、CI 和打包 VSIX 发布门禁。

0.1.5 打包热修复

  • 在 VSIX 打包规则中显式排除 *.log，避免分发 debug.log 等本地文件。

0.1.4 预览版：凭据安全、命令审查和聚焦的工具界面

  • API 凭据按规范化来源隔离存储在 VS Code Secret Storage 中。旧密钥会自动迁移；更改来源需要确认；webview 只接收配置状态和用于占位符的遮罩预览。
  • DeepSeek 请求在重定向过程中强制保持所选凭据来源，并从错误、日志、历史记录、设置、checkpoint 和可见消息中移除凭据。
  • Auto-approve 会先运行保守的本地分析器。对于仍不确定但位于工作区内的终端命令，可使用初始用户请求以及显式命名工作区文件的受限、非敏感预览进行独立 DeepSeek 审查。
  • 审查器可以批准、要求更安全的重新规划或转为手动确认。自动决定至少需要 medium-high 置信度，且绝不会绕过工作区边界，也不会委托凭据、提权、发布、部署、远程修改、外部访问、广泛终止进程或破坏性操作。
  • 相邻的推理和工具调用会折叠为可展开的 Activity 面板，并显示步骤数和汇总状态。
  • 成功的 read_file 内容不再重复显示在聊天中。文件工具提供 Open file；已完成的创建、编辑和补丁可将该次工具调用记录的精确变更作为 VS Code 原生 diff 打开。
  • 确认面板、Settings、工具控件和输入区会充分使用宽侧边栏，并在窄侧边栏中避免全局横向溢出。
  • 契约、内置工具、命令审查、聊天编排、VS Code 工作区适配器、Settings、Chat UI 和测试均按领域重组，同时保留公共消息、工具名称、设置和历史兼容性。

0.1.3 工作区安全与生成任务协调

  • 将 DeepSeek 默认输出预留从 8,192 提高到 65,536 Token，保留 384K 上限，并说明其与 1M Token 上下文窗口的关系。
  • 将工具轮次上限改为检查点：无人值守模式由 DeepSeek 判断继续、请求指示或停止；有人值守模式保留用户决定。
  • 改进 Settings、工具权限、聊天输入区/底栏和历史记录在极窄宽度下的响应式布局，包括 VS Code 最窄的侧边栏。
  • 每个会话最多运行一个生成任务，不同会话的并发数可配置为 1 到 16，默认值为 8。
  • 新增 Queue message 和 Interrupt and guide 控件、定向取消，以及绑定到生成任务的流式和工具事件。
  • 新增原子生成 checkpoint；重启后可恢复部分输出、取消未完成工具，并将排队提示作为草稿提供。
  • 引入带生成任务归属的会话 schema v2，并在激活时对有效旧历史或部分迁移历史执行经过验证的迁移；兼容逻辑会保留到计划的清理版本发布。
  • 每个生成任务固定到其会话工作区；变更类工具按工作区串行执行，只读工作可并发进行。
  • 新增带修订号的工作区绑定、确定性多根别名、断开历史重新绑定、仅 ./ 自动补全，以及不会授予工具访问权限的受限外部文件快照。
  • 新增协调式 provider 关闭流程，在扩展停用时保存 checkpoint、取消活动任务并刷新写入。
  • 新增仅由扩展宿主持有的 DeepSeek 规范工具 transcript，完整保留推理、JSON 参数、工具结果、协议顺序、checkpoint 恢复和安全重放。
  • 新增总请求预算、原子会话摘要和大型引用的原始相关行提取；每次发送最多使用四次辅助 DeepSeek 调用，并提供确定性的本地 fallback。
