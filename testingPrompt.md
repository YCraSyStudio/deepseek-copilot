estamos en un proyecto fullstack de prueba para probar tus limites como agente de desarrollo. tu objetivo será crear una app local donde se debe persistir los datos en formato json, puede ser uno o varios archivos.
el proyecto en cuestion será desarrollar un registro de horario laboral, donde simplemente se tendrá una vista con un formulario con los siguientes campos:
- DNI/NIE (seleccionable entre una lista select)
- pin
- selector de hora (por defecto hora actual pero el trabajador puede cambiar)
- 2 botones (entrada y salida)
- tema oscuro para que no gaste tanta bateria
- cualquier otra mejora que se te ocurra
- framework ASP.NET y astro web
usa comandos npm create astro@latest y dotnet para agilizar
